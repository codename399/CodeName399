Charge-cover quantity sizing patch

- Adds charge-aware quantity selection to BuyTradingService.
- Uses a minimum favourable move of 0.1% from the entry price, rounded up to the NSE tick size so the comparison uses a tradable price.
- Estimates both BUY and SELL charges for candidate quantities and selects the smallest quantity whose gross move at that price covers estimated round-trip charges.
- Searches only within the quantity already constrained by risk-based sizing, per-trade capital, and available margin. It never increases quantity beyond those limits.
- If no allowed quantity covers estimated charges, the candidate is rejected and the reason is logged instead of placing a trade that cannot meet the requirement.
- Logs quantity cap, selected quantity, projected exit price, gross move, estimated round-trip charges, and net move.
- Existing protective stop, charge-inclusive risk cap, EMA crossover entry/exit, and trailing protection are unchanged.

Verification: source structure and ZIP integrity checked. A .NET build was not run because the .NET SDK is unavailable in this environment.
